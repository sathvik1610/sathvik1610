Autonomous AI safety pipeline that discovers adversarial LLM boundary failures and generates semantic middleware protection contracts using multi-agent orchestration.

**Focus Areas:** AI Safety, CrewAI, LLM Orchestration, Middleware Enforcement, Semantic Security



## ⚡ Trisynth Compiler

A complete native compiler for NanoC implementing:

Lexing → Parsing → Semantic Analysis → IR Generation → Optimization → Native Code Generation (x86-64 & RISC-V)

**Focus Areas:** Compiler Design, ASTs, IRs, Optimization Pipelines, Code Generation

AI-powered debugging platform with:
- static analysis
- runtime diagnostics
- VS Code extension integration
- automated patch generation using LLMs

**Focus Areas:** Developer Tooling, AST Analysis, AI-assisted Repair, Extension Development

Cycle-accurate simulator implementing:
- 5-stage pipelined cores
- cache hierarchy
- synchronization barriers
- forwarding
- memory coherence behavior

**Focus Areas:** Computer Architecture, Pipelines, Cache Systems, Synchronization

## 🤖 Humanoid Walking using Deep RL

Deep Reinforcement Learning pipeline for humanoid locomotion using PPO + PyBullet with pose initialization from human images.

**Focus Areas:** Reinforcement Learning, PPO, Robotics Simulation, PyTorch

**Focus Areas:** AI Workflows, Analytics Pipelines, Automation, Full-stack Systems
